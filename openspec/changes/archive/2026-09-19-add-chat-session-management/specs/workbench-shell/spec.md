## MODIFIED Requirements

### Requirement: 无后端服务的静态展示

系统 SHALL 在后端服务不可用时仍完成工作台首屏静态区域展示，并保持报价隐藏切换、保司选择切换和文件类型校验等本地交互可用。首屏历史会话请求失败时，系统 SHALL 只在会话栏（及展开的会话面板）展示该请求的加载失败状态与重试入口，SHALL NOT 用错误状态替换、遮挡或隐藏四个区域与欢迎消息。文本消息发送依赖业务 API；API 不可用时系统 SHALL 按 `agent-chat-streaming` capability 展示发送失败，而不能导致页面崩溃或隐藏其他区域。

#### Scenario: 无后端环境打开页面

- **WHEN** 在没有运行 API 服务的环境中打开页面
- **THEN** 四个区域完整展示，报价隐藏切换、保司选择切换和文件类型校验均可用，会话栏展示自身的加载失败状态与重试入口，页面其余部分不出现请求错误

#### Scenario: 无后端环境发送文本

- **WHEN** API 服务不可用且用户发送非空文本
- **THEN** 页面保留工作台其他区域和该用户消息，显示通用发送失败提示，并允许用户再次发送

#### Scenario: 会话列表失败后重试成功

- **WHEN** 历史会话请求首次失败，用户点击会话栏的重试入口且后端已可用
- **THEN** 会话栏离开失败状态并展示当前会话标题，展开的会话面板同时展示历史会话列表，四个区域与欢迎消息自始至终保持可用
