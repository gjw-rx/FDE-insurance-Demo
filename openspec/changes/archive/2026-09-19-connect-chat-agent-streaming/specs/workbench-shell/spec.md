## MODIFIED Requirements

### Requirement: 对话输入区本地交互

系统 SHALL 在浏览器本地处理文件选择与文件类型校验，并 SHALL 按 `agent-chat-streaming` capability 处理文本发送、消息追加与流式回复。系统 SHALL NOT 上传用户选择的文件。

- 文本输入框 SHALL 接受用户输入的文本；发送按钮 SHALL 在输入内容为空时处于不可用状态，在输入内容非空且没有活动 run 时处于可用状态。
- 用户点击可用的发送按钮后，输入框内容 SHALL 被清空，页面 SHALL 追加用户消息并通过业务 API 发起 Agent run；活动 run 结束前发送按钮 SHALL 保持不可用。
- 用户点击「上传文件」入口后，系统 SHALL 打开文件选择器，且选择器 SHALL 仅允许选择图片与 PDF 文件。
- 当用户选择的文件类型不是图片或 PDF 时（选择器限制被绕过的情况），系统 SHALL 拒绝该文件并展示提示文案「仅支持图片、PDF 格式的文件」，且 SHALL NOT 记录该文件。

#### Scenario: 空输入时发送不可用

- **WHEN** 输入框内容为空
- **THEN** 发送按钮处于不可用状态，用户无法触发发送

#### Scenario: 输入内容后发送并清空

- **WHEN** 用户在输入框中输入非空文本并点击发送按钮
- **THEN** 输入框内容被清空，对话区追加该用户消息，并产生一次业务 API 创建 run 请求

#### Scenario: 活动 run 期间发送不可用

- **WHEN** 当前消息对应的 Agent run 尚未进入终态
- **THEN** 发送按钮处于不可用状态，页面不产生第二个创建 run 请求

#### Scenario: 选择图片或 PDF 文件

- **WHEN** 用户点击「上传文件」入口并在文件选择器中选择一张图片或一个 PDF 文件
- **THEN** 页面不出现错误提示，也不产生上传请求或上传结果展示

#### Scenario: 选择越界类型文件

- **WHEN** 用户通过绕过选择器类型限制的方式选中一个既非图片也非 PDF 的文件
- **THEN** 页面显示提示文案「仅支持图片、PDF 格式的文件」，且该文件不被记录

#### Scenario: 输入区不发起网络请求

- **WHEN** 用户输入文本、点击发送按钮或选择文件
- **THEN** 文本发送只产生 `agent-chat-streaming` 定义的业务 API 请求，文件选择不产生任何上传请求，且页面不直接请求 `insurance-agent` 内部接口

### Requirement: 无后端服务的静态展示

系统 SHALL 在后端服务不可用时仍完成工作台首屏静态区域展示，并保持报价隐藏切换、保司选择切换和文件类型校验等本地交互可用。文本消息发送依赖业务 API；API 不可用时系统 SHALL 按 `agent-chat-streaming` capability 展示发送失败，而不能导致页面崩溃或隐藏其他区域。

#### Scenario: 无后端环境打开页面

- **WHEN** 在没有运行 API 服务的环境中打开页面
- **THEN** 四个区域完整展示，报价隐藏切换、保司选择切换和文件类型校验均可用，页面初始状态不显示请求错误

#### Scenario: 无后端环境发送文本

- **WHEN** API 服务不可用且用户发送非空文本
- **THEN** 页面保留工作台其他区域和该用户消息，显示通用发送失败提示，并允许用户再次发送
